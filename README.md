# ERTEL Toptan

Bayilere (toptancılara) özel katalog, fiyat sorma ve sipariş uygulaması. Firebase + PWA.

- `src/` – uygulama kaynak kodu (React)
- `hosting/` – Firebase'e yüklenen hazır uygulama ve güvenlik kuralları
- `tools/build.py` – `src/`'den `hosting/public/index.html` üretir
- `main` dalına her gönderimde GitHub Actions uygulamayı Firebase Hosting'e otomatik yayınlar.

Kurulum ve kullanım: `KURULUM.md`
